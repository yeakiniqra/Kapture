Get Kapture.

Free, with no account. Kapture starts in your tray and is ready the moment it's installed.

Ubuntu & Linux

Download the .deb and double-click it to open it in App Center, or install it from the terminal:

sudo dpkg -i kapture_4.2.0_amd64.deb # if apt reports missing dependencies: sudo apt -f install

GNOME on Wayland: log out and back in once to switch on the bundled helper. After that, your shortcut captures with no flash and no permission prompt.

Download .deb

Ubuntu 22.04 or later · 64-bit (amd64) · GNOME, KDE or Xfce · X11 or Wayland

Windows

  1. Download Kapture-4.2.0-windows-x64.exe. It's a single portable file, so there's nothing to install.
  2. Keep it somewhere permanent, such as Documents\Kapture, because Kapture starts with Windows from that location.
  3. The build isn't code-signed yet, so if SmartScreen warns, choose More info → Run anyway.

Press Ctrl + Shift + S to capture, or pick Print Screen in Settings.

Download .exe

Windows 10 or 11 · 64-bit · settings in %APPDATA%\Kapture

Uninstall

Ubuntu: remove the package. Kapture hands GNOME's Print Screen shortcut back if it had taken it.

sudo apt remove kapture

Windows: turn off Start with Windows in Settings, quit Kapture from the tray, then delete the .exe.
